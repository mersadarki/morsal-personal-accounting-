# دفتر حساب

اپلیکیشن وب شخصی برای ثبت هزینه و درآمد، موجودی حساب‌ها و آمار — به‌صورت
[PWA](https://web.dev/explore/progressive-web-apps) قابل نصب روی صفحه‌ی اصلی
گوشی، با ذخیره‌سازی کامل و دائمی روی خود گوشی (بدون سرور، بدون نیاز به
اینترنت بعد از اولین بار باز کردن).

## توسعه

```bash
npm install
npm run dev
```

## ساخت نسخه‌ی نهایی

```bash
npm run build
npm run preview   # برای تست نسخه‌ی build‌شده
```

خروجی در پوشه‌ی `dist/` ساخته می‌شود؛ محتوای این پوشه یک اپ استاتیک کامل
است و روی هر هاست استاتیکی (GitHub Pages، Netlify، Vercel، Cloudflare
Pages و...) قابل انتشار است.

## نصب روی گوشی (Add to Home Screen)

بعد از این‌که آدرس اپ روی اینترنت منتشر شد (مثلاً با GitHub Pages — پایین
همین فایل توضیح داده شده):

- **اندروید (Chrome):** آدرس را باز کنید → منوی سه‌نقطه → «افزودن به صفحه‌ی
  اصلی» / «Install app».
- **آیفون (Safari):** آدرس را باز کنید → دکمه‌ی Share (مربع با فلش رو به
  بالا) → «Add to Home Screen».

بعد از نصب، آیکون دفتر حساب مثل یک اپ واقعی روی گوشی می‌آید، تمام‌صفحه باز
می‌شود (بدون نوار آدرس مرورگر) و حتی بدون اینترنت هم کار می‌کند — چون فایل‌های
اپ و فونت‌ها همراه با Service Worker از قبل روی گوشی کش می‌شوند.

## انتشار رایگان با GitHub Pages

یک workflow آماده در `.github/workflows/deploy.yml` وجود دارد که با هر
push به شاخه‌ی `main` اپ را می‌سازد و منتشر می‌کند:

1. در تنظیمات ریپازیتوری روی گیت‌هاب: **Settings → Pages → Source** را روی
   **GitHub Actions** بگذارید.
2. تغییرات را به شاخه‌ی `main` مرج/پوش کنید (یا از تب Actions، workflow را
   دستی اجرا کنید — «Run workflow»).
3. بعد از پایان اجرا، آدرس اپ زیر همان تب Pages در تنظیمات نمایش داده
   می‌شود (چیزی شبیه `https://<username>.github.io/<repo-name>/`).

## داده‌ها و پشتیبان‌گیری

همه‌چیز (تراکنش‌ها، موجودی‌ها، ماه جاری) در حافظه‌ی مرورگر همان گوشی
(`localStorage`) ذخیره می‌شود — یعنی داده‌ها فقط روی همان دستگاه هستند و با
پاک کردن Cache/داده‌های مرورگر یا حذف اپ از بین می‌روند. برای اطمینان:

- مرتب از تب **تنظیمات → پشتیبان‌گیری کامل → دانلود پشتیبان** یک فایل JSON
  بگیرید.
- برای انتقال به گوشی/مرورگر دیگر، همان فایل را از **بازیابی از پشتیبان**
  وارد کنید.

## ساختار پروژه

```
src/
  lib/          منطق مشترک: تقویم جلالی، فرمت اعداد، محاسبات آماری، ذخیره‌سازی، اکسل/پشتیبان
  components/
    home/       فرم ثبت تراکنش + لیست تراکنش‌های ماه جاری
    stats/      نمای آمار (کل/سالانه/ماهانه/ندا) + نمودارها
    settings/   پشتیبان‌گیری، خروجی/ورود اکسل، موجودی پایان ماه
```

برای تغییر آیکون اپ، فایل `scripts/icon-source.svg` را عوض کنید و
`npm run gen-icons` را اجرا کنید (نیاز به پکیج `sharp`، از قبل در
devDependencies هست).
